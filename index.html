FAQ

Will it make a finished AAA game for me?

It can push a project toward AAA quality over time — richer assets, Blender one-of-a-kind pieces, more runs, and your taste checks along the way. You get the studio pipeline: start with a grey-box, then add assets or whatever you need. The final calls stay with you.

Can it make a full hunting-style game?

Yes. That class of game is in range: pitch, a Unity project, guns and systems, then iterate. With time and the assets you bring, you can build a full hunting-style game. It will not instantly clone any specific title. You supply the references, art, and judgment; Game Bot keeps the pipeline moving.

Does it need the cloud or a subscription?

No. It runs local models through Ollama on your PC, so there are no cloud usage caps or per-message fees.

Does it publish to Steam for me?

It prepares store copy and checklists. Steam tax forms, App ID purchases and release clicks always stay with you.

What if I don't have an NVIDIA GPU?

Today Game Bot needs an NVIDIA GPU with 8 GB+ VRAM. AMD support is coming soon. Please check your GPU before buying.

How can I pay?

Refunds and licensing?

All sales are final — no refunds. One purchase = one PC: Game Bot binds to the computer it's installed on. Moving to a new PC needs a new purchase or an approved license transfer. Software is provided as-is.

Do I need Unity?

Only if you want the project opened and built in Unity. Unreal works the same way once installed. Design, docs, Blender assets and prep steps work without either engine.
