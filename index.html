Requirements

Game Bot is a Windows desktop app that runs local AI models on your own hardware.

Windows PC

Windows 10 or 11 (64-bit).

Graphics card

NVIDIA RTX 20 series or newer, or AMD RX 6000 series or newer, with at least 8 GB VRAM; 12 GB recommended. On supported AMD cards, Game Bot uses Vulkan when needed and automatically retries at a lower context if the GPU driver resets.

Ollama + local models

Game Bot’s own offline model is the default and runs through Ollama on your PC. Installing Ollama and the first model download need internet. You can also use other Ollama models already on your PC, a local server such as LM Studio or llama.cpp, or — optionally — your own cloud API key. Cloud models need internet and send prompts off the PC.

Unity / Unreal (optional)

Needed if you want Game Bot to open and build the project. With Unreal Editor installed, Game Bot can create the Unreal project and package a playable Windows build. Blender helps for one-of-a-kind assets.

Disk space

Leave room for local models (several GB each) and your projects.

Internet

Needed to install Game Bot and Ollama and to download models. Day-to-day local AI runs on your PC with no cloud LLM subscription. Downloading assets, web research, optional cloud models, and other online steps still need a connection. Cloud models send prompts off the PC.

FAQ

Will it make a finished AAA game for me?

It can push a project toward AAA quality over time — richer assets, Blender one-of-a-kind pieces, more runs, and your taste checks along the way. You get the studio pipeline: start with a grey-box, then add assets or whatever you need. The final calls stay with you.

Can it make a full hunting-style game?

Yes. That class of game is in range: pitch, a Unity project, guns and systems, then iterate. With time and the assets you bring, you can build a full hunting-style game. It will not instantly clone any specific title. You supply the references, art, and judgment; Game Bot keeps the pipeline moving.

Can I use my own model?

Yes. Game Bot’s own offline model stays the default. In Settings you can pick another Ollama model already on your PC, point at a local server such as LM Studio or llama.cpp, or enter your own cloud API key (OpenAI, Anthropic, OpenRouter, or xAI). Cloud models send prompts off the PC.

Did the lighting and visuals improve?

Yes. Outdoor lighting and post-processing were tuned so scenes are less blown out. Missing foliage textures no longer show as magenta, and starting health displays at full.

Does it need the cloud or a subscription?

No cloud LLM subscription is required. Game Bot’s own offline model is the default, so local use has no cloud usage caps or per-message fees. You can optionally use a cloud model with your own API key; that path does send prompts off the PC.

Does daily use need the internet?

Local AI chat and generation run on your PC after setup. Internet is required to install Game Bot and Ollama and to download models the first time. You still need a connection when Game Bot downloads assets, does web research, uses an optional cloud model, or anything else that pulls from the network.

Does it publish to Steam for me?

It prepares store copy and checklists. Steam tax forms, App ID purchases and release clicks always stay with you.

What GPU do I need?

NVIDIA RTX 20 series or newer, or AMD RX 6000 series or newer, with at least 8 GB VRAM; 12 GB recommended. Game Bot automatically picks the AI model for your card. On supported AMD cards it uses Vulkan when needed, sizes context for 8 GB VRAM, and retries at a lower context if the driver resets instead of hanging. CPU-only is much slower and is not recommended.

What languages does the app support?

The current Game Bot build includes a language/region selector, so the app UI is multi-language. Choose your language and region in the app.
