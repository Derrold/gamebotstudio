Requirements

Game Bot is a Windows desktop app that runs local AI models on your own hardware.

Windows PC

Windows 10 or 11 (64-bit).

GPU with 8 GB+ VRAM

NVIDIA or AMD. 12 GB+ automatically gets a larger, smarter model.

Ollama + local models

Uses Ollama to run local LLMs. Installing Ollama and the first model download need internet. Local chat and generation then run on your PC.

Unity / Unreal (optional)

Needed if you want Game Bot to open and build the project. Blender helps for one-of-a-kind assets.

Disk space

Leave room for local models (several GB each) and your projects.

Internet

Needed to install Game Bot and Ollama and to download models. Day-to-day local AI runs on your PC with no cloud LLM subscription. Downloading assets, web research, and other online steps still need a connection.

FAQ

Will it make a finished AAA game for me?

It can push a project toward AAA quality over time — richer assets, Blender one-of-a-kind pieces, more runs, and your taste checks along the way. You get the studio pipeline: start with a grey-box, then add assets or whatever you need. The final calls stay with you.

Can it make a full hunting-style game?

Yes. That class of game is in range: pitch, a Unity project, guns and systems, then iterate. With time and the assets you bring, you can build a full hunting-style game. It will not instantly clone any specific title. You supply the references, art, and judgment; Game Bot keeps the pipeline moving.

Does it need the cloud or a subscription?

No cloud LLM subscription. It runs local models through Ollama on your PC, so there are no cloud usage caps or per-message fees.

Does daily use need the internet?

Local AI chat and generation run on your PC after setup. Internet is required to install Game Bot and Ollama and to download models the first time. You still need a connection when Game Bot downloads assets, does web research, or anything else that pulls from the network.

Does it publish to Steam for me?

It prepares store copy and checklists. Steam tax forms, App ID purchases and release clicks always stay with you.

What GPU do I need?

Game Bot needs a GPU with 8 GB+ VRAM. It automatically picks the model for NVIDIA and AMD cards; 12 GB+ gets a larger one. CPU-only is much slower and is not recommended.

What languages does the app support?

The current Game Bot build includes a language/region selector, so the app UI is multi-language. Choose your language and region in the app.
